# openindeo

A small, dependency-free C99 decoder for **Intel Indeo Video Interactive 4 and 5** (`IV41`,
`IV50`), the codecs inside many 1990s and early-2000s AVI files and games. It has no external
dependencies, needs no codec installation and uses the MIT licence.

```c
#include "openindeo.h"

oi_decoder *d = oi_create(fourcc);              /* the AVI stream's fourcc, e.g. OI_FOURCC('I','V','5','0') */
for (each video chunk of the AVI) {
    oi_frame f;
    if (oi_decode(d, data, size, &f) == OI_OK)
        oi_to_rgb24(&f, rgb, f.width * 3);      /* or use f.y / f.u / f.v (planar 4:1:0) */
}
oi_destroy(d);
```

An empty chunk (a dropped frame) and an Indeo "null" frame repeat the previous picture
(`f.is_new == 0`).

## Status

Decodes bit-exactly (every sample of every picture equal to FFmpeg's decoder) on the test set:
18 videos from *One Must Fall: Battlegrounds*, 16 Indeo 5 and 2 Indeo 4, from 32×32 to 128×128, intra and inter frames,
half-pel motion, 4×4 and 8×8 blocks, custom codebooks and run/value corrections.

| Feature | Indeo 5 | Indeo 4 |
|---|---|---|
| Single-band pictures, intra frames | yes | yes |
| Inter frames | yes | written, untested |
| Non-reference and null frames | written, untested | written, untested |
| Slant transforms | yes | yes |
| Haar transforms | n/a | not yet (reported as unsupported) |
| Scalable (wavelet, four-band luma) pictures | not yet | not yet |
| Bidirectional frames | n/a | written, untested |
| Transparency | n/a | not yet (decodes the picture; no alpha) |
| Password-protected streams | the lock word is skipped | the lock word is skipped |

Anything unsupported returns `OI_ERR_UNSUPPORTED` rather than a wrong picture. "Written,
untested" means the code exists but no test stream reaches it; see the issues.

## Building

```sh
cmake -S . -B build && cmake --build build
```

This builds the static library `openindeo` and the `oi-avi` tool (`OPENINDEO_TOOLS=OFF` leaves
the tool out when the project is added with `add_subdirectory`).

## Testing

`tools/compare.py build/oi-avi files.avi...` decodes each file with `oi-avi` and with an
installed `ffmpeg` as a reference, then compares the pictures plane by plane. FFmpeg is only run
as an external program; none of its code is used.

The test set (videos from *One Must Fall: Battlegrounds*) is not included, since it belongs to
the game; any Indeo AVI files work. Features the test set does not exercise are tracked in the
issues labelled `untested`.

## Tables

The format's fixed tables (Huffman codebook layouts, run/value maps, scan orders,
dequantisation matrices, picture sizes) are in `src/tables.c`, generated by
`tools/gen_tables.py`. They are format constants, the same in every implementation. The
provisional source is FFmpeg's published tables (the numbers only). Intel's own codec DLLs
(`ir41_32`, `ir50_32`) are to be the source of record, and the two will be diffed.
